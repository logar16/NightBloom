About the examples

These are controlled demonstrations, not screenshots of your current composition.

The overlapping tiles have a deliberately introduced exposure difference. The surroundings are a blurred same-band stand-in with a deliberate tone mismatch.

The default reference is a single normalized built source, with no artificial surroundings. “Uncorrected demo composite” is a stress test, not the incoming image or NightBloom’s normal build result.

Build operations use the native backend. Matching, feathering and compositing use the existing reference renderer. The separate Sky example runs the actual frontend Auto code and SVG display filter on the base display image. It never changes the build comparison, edits or exports.

Matching and feathering do not guarantee a seamless result: additive overlap can remain brighter, and Auto can brighten noise. All combinations keep the same color and blend settings.
